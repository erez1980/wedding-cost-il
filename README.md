# חתונה בתכלס

מחשבון סטטי בעברית להערכת עלות חתונה בישראל. האתר מחשב את עלות האוכל והאולם, ספקים והפקה, ורשת ביטחון מפורשת — כך שהתקציב הכולל והמחיר לאורח נשארים שקופים.

## נוסחת החישוב

```text
סכום בסיס = (מספר אורחים × מחיר מנה) + צילום + מוזיקה / DJ + לבוש ואיפור + עיצוב ותוספות
רשת ביטחון = סכום בסיס × אחוז רשת הביטחון
תקציב כולל = סכום בסיס + רשת ביטחון
מחיר לאורח = תקציב כולל ÷ מספר האורחים
```

אפשר לבחור רשת ביטחון של 0%, 5%, 10%, 15% או 20%. היא מוצגת כשורה נפרדת ולא נטמעת בסכום אחר. קלטים שליליים, ריקים או חריגים מסומנים למשתמש; החישוב משתמש בערכים תקינים בלבד.

## פיתוח מקומי

דרישה: Node.js 20 ומעלה.

```bash
npm ci
npm test
npm run build
```

`npm run build` מייצר static export לתיקיית `out/`, המתאימה ל־GitHub Pages. ההגדרה משתמשת בנתיבים יחסיים כדי לעבוד גם תחת נתיב repository וגם בדומיין מותאם אישית.

## SEO

האתר כולל metadata, Open Graph/Twitter cards, canonical URL, JSON-LD מסוג `WebApplication`, ונתיבים סטטיים ל־`robots.txt` ו־`sitemap.xml`.

## פריסה

Workflow ב־GitHub Actions מריץ בדיקות ובנייה בכל push/PR ל־`main`, ומפרסם את `out/` ל־GitHub Pages ב־push ל־`main`.
